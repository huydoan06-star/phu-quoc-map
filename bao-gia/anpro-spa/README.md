# Báo giá Anpro Spa

Trang báo giá dịch vụ cho Anpro Spa (Phú Quốc): gói thiết kế decor & nhận diện, quảng cáo RedNote / Google Maps, website riêng.

- `index.html` — trang báo giá (tĩnh, không cần build). Có `noindex` để không lên kết quả tìm kiếm.
- `img/` — ảnh phối cảnh minh hoạ (AI) dùng trên trang.
- `in-an/` — file in: menu A3 mặt 1 và mặt 2, bộ nhận diện.

Link sau khi merge vào `main`: https://huydoan06-star.github.io/phu-quoc-map/bao-gia/anpro-spa/
