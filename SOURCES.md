## Photos (v3)
- Source: Wikimedia Commons only — files under CC BY / CC BY-SA (2.0–4.0); full list with author, licence, file page and capture time in **CREDITS.md**.
  Search: Commons API (`list=categorymembers` crawl of Category:Phu Quoc, `generator=geosearch` around each spot, `prop=imageinfo` with `extmetadata` + EXIF).
- Not used: Unsplash / Pexels (their APIs need an account/key — we never create accounts or keys); Facebook / Instagram / TikTok / Google Maps user photos and any all-rights-reserved images (never scraped).

## Map imagery and terms (checked 2026-10-17)
- **Day: Sentinel-2 cloudless 2024 by EOX IT Services GmbH** — https://s2maps.eu · WMTS `s2cloudless-2024_3857`. Licence **CC BY-NC-SA 4.0** (non-commercial). Attribution shown in the map: "Sentinel-2 cloudless – https://s2maps.eu by EOX IT Services GmbH (Contains modified Copernicus Sentinel data 2024)".
  ⚠ **Before any affiliate/commercial use**, switch to the 2016 layer `s2cloudless_3857` (**CC BY 4.0**, commercial use allowed with attribution) — one line in `js/mapfx.js` (`IMAGERY`) — or buy an EOX commercial licence.
- **Not used: Esri World Imagery.** Esri's terms allow free use only with an ArcGIS (Developer/Location Platform) account and API key and only for non-revenue apps; we don't create accounts, and the site plans affiliate links.
- **Not used: Google satellite** (needs a Google Maps API key + billing — deferred by the owner).
- **Night lights: NASA GIBS — VIIRS Black Marble** (`VIIRS_Black_Marble`, GoogleMapsCompatible_Level8, max native zoom 8, upscaled and softened). NASA imagery is public domain; credit "NASA Earth Observatory / GIBS" shown. https://www.earthdata.nasa.gov/engage/open-data-services-software/earthdata-developer-portal/gibs-api
- **Place labels**: drawn by the site itself (no third-party label tiles); names/positions from OpenStreetMap (© OpenStreetMap contributors, ODbL).
- Fallback: if the imagery host is unreachable the map switches to standard OpenStreetMap tiles (tile usage policy: https://operations.osmfoundation.org/policies/tiles/).
- Warm "town glow" halos at night are decorative (positions of Dương Đông, An Thới/Sunset Town, Grand World/Bãi Dài, the airport, Bãi Trường and Hàm Ninh), not measured light data.
- Day/night switches automatically at the computed sunrise/sunset for Phú Quốc (NOAA solar-position approximation, lat 10.22, lng 103.96, UTC+7); a sun/moon button overrides it for the session.
