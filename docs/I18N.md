# Adding or editing a language

1. Copy `i18n/en.json` to `i18n/<code>.json` (BCP-47 code, e.g. `fr`, `de`, `ms`, `km`, `kk`).
2. Translate the values (keep the keys). Missing keys fall back to English automatically.
3. Set `_meta`: `{ "language": "Français", "machineTranslated": true|false, "needsReview": true|false }`.
   When `machineTranslated` is true the footer shows a "machine-translated, awaiting review" note.
4. Add one line to `i18n/languages.json`: `{ "code": "fr", "nativeName": "Français", "dir": "ltr" }`.
5. Optional: add `"fr": "…"` to the `name` / `guide` / `tips` / `bestTime` fields in `data/spots.json` (English is used otherwise).

That's it — no code change. Language is picked from `?lang=<code>`, then the visitor's saved choice, else English.
